# ⚙️ Configurer ses touches

### Fonctionnalité de configuration des touches de FiveM

## Information

Vous pouvez accéder a cette fonctionnalité en allant dans les paramètres :  *Réglages -> Config. des touches -> FiveM*

## Comment dé-configurer une touche

**Vous avez deux options :**

**Option 1 :** saisissez « unbind keyboardinput_parameter » dans la touche F8.

**Option 2 :** accédez à *C:\Users[USERNAME]\AppData\Roaming\CitizenFX*, ouvrez *fivem.cfg* et supprimez les lignes contenant ce nom de ressource. Redémarrez ensuite FiveM. Les raccourcis clavier reviendront aux valeurs par défaut définies dans la configuration.
