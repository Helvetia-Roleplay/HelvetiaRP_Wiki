# 📇 Liste Exhaustive des Commandes

Toutes les commandes textuelles disponibles sur le serveur **HelvetiaRP V2** classées par catégorie.

---

## 🏛️ 1. Commandes Générales & Utilitaires

| Commande | Utilisation & Description |
| :--- | :--- |
| `/guide` | Ouvre le carnet / guide informatif de la ville avec de nombreuses astuces. |
| `/report [Message]` | Envoie un ticket d'assistance immédiat à l'équipe de modération/staff connectée. |
| `/job` | Affiche votre métier actuel, votre grade et votre salaire en direct. |
| `/gang` | Affiche le statut, l'organisation ou le groupe illégal auquel vous appartenez. |
| `/bank` | Consulte le solde actuel de votre compte bancaire. |
| `/bill` | Affiche l'historique et la liste de vos factures en attente de paiement. |
| `/cashgive` | Ouvre le menu d'échange d'argent liquide avec le citoyen le plus proche. |
| `/myfinance` | Ouvre la gestion financière des véhicules achetés à crédit (mensualités, solde). |

---

## 🎭 2. Roleplay & Expressions

| Commande | Utilisation & Description |
| :--- | :--- |
| `/me [Action]` | Décrit une action physique ou corporelle de votre personnage (*Ex: `/me vérifie son rétroviseur`*). |
| `/do [Description]` | Décrit un élément d'ambiance ou pose une question sur l'état d'un joueur (*Ex: `/do Sent-on une odeur d'alcool ?`*). |
| `/ooc [Message]` | Envoie un message dans le canal hors-roleplay (à utiliser avec parcimonie). |

---

## 🕺 3. Emotes, Démarches & Attitudes

| Commande | Utilisation & Description |
| :--- | :--- |
| `/e [Nom]` | Joue une animation ou une posture spécifique (*Ex: `/e sit`, `/e coffee`, `/e smoke`*). |
| `/emotebind [num4-num9] [Nom]` | Attribue une emote favorite sur le pavé numérique (<kbd>Num 4</kbd> à <kbd>Num 9</kbd>). |
| `/walks` | Affiche la liste des styles de démarche disponibles. |
| `/walk [Nom]` | Définit une démarche personnalisée (décontractée, blessée, pressée, etc.). |
| `/reset walk` | Réinitialise la démarche de base de votre personnage. |
| `/moods` | Affiche la liste des expressions faciales (humeurs). |
| `/reset mood` | Restaure le visage neutre par défaut. |
| `/e medbag` | Animation de transport d'une trousse médicale de premiers secours. |

## 🚗 4. Véhicules & Clés

| Commande | Utilisation & Description |
| :--- | :--- |
| `/givekey` | Confie un double des clés du véhicule le plus proche au joueur à vos côtés. |

---

## 📱 5. Téléphone & Dépannage UI

| Commande | Utilisation & Description |
| :--- | :--- |
| `/togglephone` | Force l'ouverture ou la fermeture de votre smartphone. |
| `/givecontact` | Transmet instantanément votre carte de contact au citoyen le plus proche. |
| `/resetPhonePos` | Réaligne et recentre l'affichage du téléphone sur votre écran. |
| `/resetZoom` | Restaure la mise à l'échelle par défaut du smartphone. |
| `/propfix` | Élimine tout objet ou accessoire (téléphone, tasse, boîte) resté coincé dans votre main. |

---

## 🚨 6. Services d'Urgence Cantonaux

| Commande | Utilisation & Description |
| :--- | :--- |
| `/117m [Message]` | Transmet un message géolocalisé à la **Police Cantonale**. *(Privilégiez l'app Téléphone)* |
| `/117a [Message]` | Transmet un message **anonyme** à la **Police Cantonale**. |
| `/144m [Message]` | Transmet un appel d'urgence aux **Ambulances / Réseau Hospitalier**. *(Privilégiez l'app Téléphone)* |
