# 🎙️ Chat Vocal & Radio Cantonale

HelvetiaRP V2 utilise le système vocal 3D immersif **PMA-Voice** avec gestion de l'audio spatialisé natif et effets radio réalistes.

---

## ⚙️ 1. Paramétrer son Chat Vocal dans GTA / FiveM

Pour que vos communications fonctionnent parfaitement en jeu, vérifiez les réglages audio :

1. Ouvrez le menu pause avec <kbd>Échap</kbd>.
2. Allez dans `Paramètres` ➔ `Chat vocal`.
3. Configurez les options suivantes :
   - **Chat vocal activé** : `Avec` (Oui)
   - **Dispositif de sortie** : Sélectionnez votre casque ou haut-parleurs habituels.
   - **Microphone actif** : `Avec` (Oui)
   - **Dispositif d'entrée** : Sélectionnez votre microphone principal.
   - **Mode chat vocal** : `Appuyer pour parler` (recommandé) ou `Détection vocale`.
   - **Volume du chat vocal** : Ajustez selon le volume souhaité pour entendre vos interlocuteurs.
   - **Sensibilité / Volume du microphone** : Réglez pour que votre voix soit claire et sans coupure.

## 🗣️ 2. Gestion des Portées de Voix

Adaptez votre volume de projection vocale en fonction de la situation RP :

- **Touche de bascule** : <kbd>à</kbd> ou <kbd>²</kbd> (*Touche Grave*).
- **Les 3 modes disponibles** :
  1. 🤫 **Chuchoter (1.5 mètres)** : Pour les échanges discrets, confidences ou interrogatoires secrets.
  2. 🗣️ **Normal (8 mètres)** : Distance de conversation standard du quotidien.
  3. 📢 **Crier (25 mètres)** : Pour les situations d'urgence, appels à l'aide ou avertissements extérieurs.

Le cercle ou l'icône sur votre HUD change de taille et de couleur pour vous indiquer le mode actif.

---

## 📻 3. Utilisation de la Radio & Fréquences

- **Allumer la radio** : Utilisez l'item Radio depuis votre inventaire (<kbd>TAB</kbd>).
- **Rejoindre une fréquence** : Saisissez le canal radio souhaité (ex: *Canal 1* pour les communications inter-services, ou fréquences privées pour votre groupe/entreprise).
- **Parler à la radio (Push-To-Talk Radio)** : Maintenez votre touche radio (<kbd>ALT Gauche</kbd> ou <kbd>Verr Maj</kbd>). Une animation d'épaule se déclenche avec un filtre audio talkie-walkie.
- **Régler le volume de la radio** : Vous pouvez ajuster le volume sonore directement dans l'interface de la radio.
