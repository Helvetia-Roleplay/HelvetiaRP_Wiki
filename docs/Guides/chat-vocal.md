# 🎙️𝐂𝐡𝐚𝐭 𝐯𝐨𝐜𝐚𝐥

### [hashtag](#parametrer-le-chat-vocal)Paramétrer le chat vocal

Une fois dans le menu pause (appuyer sur ESC) aller dans : Réglages -&gt; Chat vocal

ESC -&gt; Réglages -&gt; Chat vocalPour que le chat vocal fonctionne, vérifiez si les points suivants sont activés :

Chat vocal actif - Avec

Dispositif de sortie - Sortie audio (Casque, écouteur, etc…)

Microphone actif - Avec

Dispositif d’entrée - Entrée audio (Micro, micro casque, etc…)

Mode chat vocal - Appuyer pour parler

De plus, sur cette page, vous devez régler les différents volumes du serveur et du chat vocal en fonction de vos ressentis et de l&#x27;avis des autres joueurs.

Volume du chat vocal - Régler le volume du chat vocal des joueurs

Volume du microphone - Régler le volume de son micro

### [hashtag](#parametrer-la-touche-appuyer-pour-parler)Paramétrer la touche Appuyer pour parler
La procédure suivante doit être suivie pour localiser ou configurer la touche Appuyer pour parler :
Une fois dans le menu aller dans : Réglages -&gt; Config. touches -&gt; GTA Online -&gt; Appuyer pour parler
ESC -&gt; Réglages -&gt; GTA Online -&gt; Appuyer pour parlerFaites attention à bien garder la touche N en PRIMAIRE et mettre votre touche personnalisée dans SECONDAIRE car cela peut créer quelques problèmes chez certaines personnes
